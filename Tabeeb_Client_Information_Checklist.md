# Tabeeb client information tracker

Updated: 9 October 2026 (Asia/Dhaka). This is an information tracker, not a compliance certification.

Address and main telephone are client-confirmed. Their exact values were not included in the latest text, so this checklist does not invent them. Client-supplied information is distinct from document verification.

Update each row when more information arrives. Use N/A for items that do not apply. A checked Received box records receipt only; it does not mean document verification or completed follow-up. Receiving information does not automatically approve publication.

For every row, record: date received; source/evidence reference; owner; next action; last confirmed date; expiry/review date if relevant; publication state (Draft/Hidden/Published); publication approval; date updated. Never record account passwords here.
